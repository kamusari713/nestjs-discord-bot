# NestJS controllable Discord Bot

## Overview

This project serves as a practical demonstration of **NestJS** capabilities, showcasing structured architecture, *Dependency Injection (DI)*, *modular design*, and *integration with external APIs like **Discord.js***. It implements a controllable Discord bot that enforces scheduled *"quiet time"* windows on servers, restricting voice channel access. During these periods, the bot disconnects users and deletes channels. It includes multiple modes, such as a strict mode that snapshots voice channels before quiet time, enforces deletions, and restores the state afterward.

## Key NestJS Features Demonstrated

- **Modular Architecture**: Organized into modules for auth, discord, guilds, listeners, quiet, and snapshots.
- **Dependency Injection**: Efficient management of services, controllers, and providers.
- **Configuration and Scheduling**: Using @nestjs/config and @nestjs/schedule for dynamic settings and timed tasks.
- **Database Integration**: With TypeORM for handling snapshots and guild configurations.
- **Event Handling**: Custom listeners for real-time Discord events.
